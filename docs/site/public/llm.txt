# @koalarx/utils

> Biblioteca utilitária TypeScript/JavaScript para máscaras, datas, arrays e conversões do ecossistema Koala.

Documentação otimizada para LLMs. Cada tópico aponta para o arquivo Markdown correspondente — sem duplicar conteúdo.

Site: https://utils.koalarx.com

## Core

- [KlString](markdown/pt/core/kl-string.md): Máscaras CPF/CNPJ, camelCase, moeda, Base64 e split fluente.
- [KlNumber](markdown/pt/core/kl-number.md): Formatação monetária e números aleatórios.
- [KlDate](markdown/pt/core/kl-date.md): Formatação, fuso, add/sub e feriados opt-in.
- [KlTime](markdown/pt/core/kl-time.md): Manipulação de horários com format/add/sub.
- [KlArray](markdown/pt/core/kl-array.md): clearEmptyValues, split, orderBy e shuffle tipados.
- [KlDelay e KlCron](markdown/pt/core/kl-delay-cron.md): delay assíncrono e medição de duração.
- [Feriados](markdown/pt/core/holidays.md): Opt-in de date-holidays para isHoliday e skipHolidays.
