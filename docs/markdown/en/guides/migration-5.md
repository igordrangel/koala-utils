# Migration 5.0

1. Removal of `@koalarx/utils/light`
2. Opt-in holidays (`date-holidays` + `@koalarx/utils/holidays`)
3. `KlArray.map` / `KlString.split` return `KlArray`
4. New `operators` and `prototypes` subpaths
5. Internal `core/` layout (stable public imports)
6. Web docs + `llms.txt` generated from Markdown sources
